# Community conduct

Treat users and contributors respectfully. Critique ideas with evidence and allow questions, disagreement and correction. Harassment, threats, discriminatory abuse and disclosure of private information are unacceptable.

The maintainer may request edits, remove harmful content or restrict participation proportionately. Non-sensitive project concerns can be raised in a repository issue. Never post personal details or confidential allegations publicly. Use GitHub's built-in Report abuse tools for conduct that violates GitHub policies, including concerns involving the maintainer. A dedicated private project conduct contact and independent project escalation route are not yet established; no confidential reporting service is claimed by this policy. Security vulnerabilities use the private process in SECURITY.md.
