# Contributing

PMCAS is maintained by Maged Taha. PMCAS uses the MIT License. By submitting a contribution for inclusion, you agree to license it under the same terms and confirm you have the right to submit it. No copyright assignment or separate CLA is required.

For future bug reports, provide versions, reproduction steps, expected/actual results and sanitized evidence. Never include client records, credentials, database dumps or private workspace links. Security findings belong in a verified private reporting channel described in SECURITY.md.

Changes should explain the user problem, changed behavior and validation. Keep scoring/recommendation logic separate from rendering. Scoring changes need examples covering missing answers, weighting, rounding and confidence. Preserve synthetic demo data and upstream notices. Do not claim historical test results as current checks.
