# Roadmap

PMCAS is an early local workflow, not a complete hosted service. These items are proposals, not completed features or commitments.

- Expand production save-feedback regression coverage to other forms and regular browsers; the updated response-save scenario passed.
- Verify setup from a clean checkout against a disposable database.
- Complete CSV/Excel intake with validation, row-level errors and synthetic fixtures.
- Replace prioritization placeholders with documented consultant-editable rules.
- Test export rendering in common spreadsheet tools.
- Implement and verify Arabic/RTL support.
- Design authentication and tenant isolation before considering a hosted deployment.

Useful initial contributions include a minimal reproduction for the save feedback issue, scoring edge cases, setup corrections and synthetic export examples. Discuss larger workflow changes before implementation. Keep actual client material out of issues, tests and examples.
